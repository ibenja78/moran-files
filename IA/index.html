01 / FUNDAMENTOS

IA tradicional vs. IA generativa

No todos los sistemas de Inteligencia Artificial funcionan de la misma manera.

◈
IA TRADICIONAL

Decidir y clasificar

La IA tradicional utiliza reglas, algoritmos o modelos entrenados para analizar información, clasificar datos y tomar decisiones dentro de un conjunto de posibilidades.

  • Clasificación de información
  • Predicción de resultados
  • Detección de patrones
  • Sistemas expertos
✦
IA GENERATIVA

Crear contenido

La IA generativa utiliza modelos capaces de producir contenido nuevo a partir de patrones aprendidos durante su entrenamiento.

  • Texto
  • Imágenes
  • Audio
  • Código y otros contenidos
DIFERENCIA FUNDAMENTAL

Un sistema tradicional suele responder a una tarea definida mediante clasificación, predicción o reglas. Un sistema generativo puede utilizar patrones aprendidos para producir una nueva respuesta.

02 / APRENDIZAJE

Machine Learning & Deep Learning

Dos conceptos fundamentales para entender cómo las máquinas pueden aprender a partir de datos.

IA Inteligencia Artificial
ML Machine Learning
DL Deep Learning
01

Machine Learning

Es un enfoque en el que un algoritmo aprende patrones a partir de datos para realizar una tarea sin tener que programar manualmente cada regla.

datos → entrenamiento → modelo
02

Deep Learning

Es una rama del Machine Learning que utiliza redes neuronales con múltiples capas para aprender representaciones complejas.

entrada → capas → salida
03

Relación

Deep Learning forma parte de Machine Learning, y Machine Learning forma parte del campo más amplio de la Inteligencia Artificial.

IA ⟶ ML ⟶ DL
03 / MODELOS DE LENGUAJE

¿Qué es un LLM?

Los grandes modelos de lenguaje son una de las tecnologías centrales de la IA generativa actual.

Large Language Model

Un LLM es un modelo de Inteligencia Artificial entrenado con grandes cantidades de datos lingüísticos para aprender patrones del lenguaje.

Cuando recibe una entrada, calcula qué secuencia de tokens puede producir como continuación, utilizando los patrones aprendidos durante su entrenamiento.

Entrada → modelo → probabilidades → salida
01
Datos

Textos, código y otros datos utilizados para entrenar el modelo.

02
Entrenamiento

El modelo ajusta sus parámetros para aprender patrones.

03
Inferencia

El modelo utiliza lo aprendido para generar una respuesta.

FASE 01

Entrenamiento

Es el proceso costoso de aprendizaje. El modelo procesa grandes cantidades de datos y modifica sus parámetros mediante optimización.

→
FASE 02

Inferencia

Es cuando utilizamos el modelo. Recibe una entrada y genera una respuesta utilizando los parámetros aprendidos.

05 / CLASIFICACIÓN

Tipos de modelos

Los modelos pueden clasificarse utilizando diferentes criterios.

Categoría Características Hardware Uso habitual
Pequeños Menor cantidad de parámetros y recursos. CPU o GPU común Tareas locales y dispositivos.
Medianos Mayor capacidad y contexto. GPU dedicada Programación, análisis y asistentes.
Grandes Alta capacidad de razonamiento y generación. Hardware especializado Investigación y tareas complejas.
Especializados Optimizados para una tarea o dominio. Variable Código, imágenes, audio, ciencia, etc.
Importante:

El tamaño de un modelo no determina por sí solo su utilidad. La arquitectura, los datos, el entrenamiento, la especialización y el hardware también influyen en su rendimiento.

06 / ECOSISTEMA

Más allá del modelo

Un sistema moderno de IA puede conectarse con herramientas, datos y servicios externos.

P

Plugins

Extensiones que agregan capacidades o conectan un sistema de IA con servicios externos.

C

Conectores

Permiten que una aplicación de IA acceda a información o servicios externos autorizados.

M

MCP

Model Context Protocol es un protocolo abierto diseñado para conectar modelos con herramientas y fuentes de contexto mediante una interfaz estandarizada.

S

Skills

Capacidades o instrucciones especializadas que permiten organizar cómo un agente realiza determinadas tareas.

MODELO + CONTEXTO + HERRAMIENTAS + SKILLS → AGENTE
07 / SEGURIDAD

Amenazas de la IA

Las capacidades de la Inteligencia Artificial también generan nuevos riesgos técnicos y sociales.

01

Deepfakes

Contenido audiovisual generado o manipulado mediante IA que puede utilizarse para suplantaciones y desinformación.

MANIPULACIÓN
02

Phishing automatizado

Los modelos generativos pueden facilitar la creación de mensajes personalizados utilizados en campañas de ingeniería social.

CIBERSEGURIDAD
03

Prompt Injection

Un atacante puede intentar introducir instrucciones maliciosas para modificar el comportamiento de un sistema conectado a herramientas.

SEGURIDAD DE IA
04

Errores y alucinaciones

Un modelo puede generar información incorrecta presentada de manera convincente. Por eso las respuestas deben verificarse en tareas críticas.

FIABILIDAD
CASO DEL MUNDO REAL

Contenido sintético y desinformación

Durante los últimos años se han documentado casos de imágenes, audios y vídeos generados o modificados mediante IA utilizados para hacerse pasar por personas reales o difundir información falsa.

Regla práctica: verificá el origen de contenido sensible antes de compartirlo o utilizarlo como evidencia.
